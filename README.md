## 🎯 Project Overview

> A **C++ OpenCV case study** that simulates a real-world **physical access control system** using ArUco fiducial markers embedded in security badges.

- **Library:** OpenCV 4.6 (ArUco contrib module)
- **Domain:** Security / Access Control
- **Language:** C++17 with Python evaluation scripts

> 🚧 *This project is currently under active development. Sections will be updated as features are completed.*
